A make.fun entry for [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

`main.ts` (Node 22, stdlib only) writes exactly one line — 100 characters — to `/output/entry.txt`:

> My cat pushed my glass off the table, watched it shatter, then looked at me like I should apologize.

The setup is the cat knocking the glass off the table; the turn is the stare afterwards — the cat silently blaming the owner for the mess it just made. No tired cat pun, nothing to explain, and short enough to retell to a friend the same day.

Run it with:

```sh
node main.ts
```
